# 🎙️ 프로젝트 소개 (Project Overview)
개인적인 고민과 개발을 주제로 서로 소통하는 커뮤니티 서비스입니다.  
사용자가 게시글과 댓글을 통해 의견을 나누고, 실시간 채팅으로 자유롭게 대화할 수 있는 풀스택 개인 프로젝트입니다.

---

## 💻 Front-end 소개
- **구현 방식**: 서버에서 렌더링된 HTML + 바닐라 JavaScript로 동적인 UI 구성
- **주요 기능**
  - 게시글 목록 / 상세 / 작성 / 수정 / 삭제 화면 구현
  - Fetch API를 활용한 백엔드 REST API 연동
  - 로그인 / 로그아웃, 사용자 정보 조회 등 인증 관련 화면 처리
  - 실시간 채팅 화면 및 메시지 리스트 렌더링
- **특징**
  - 프레임워크 없이 순수 JS로 SPA에 가까운 사용자 경험 제공
  - 공통 UI 요소와 유틸 스크립트 모듈화로 유지보수성 향상
  - 반응형 레이아웃 구성으로 다양한 해상도 지원
