# 🎙️ 프로젝트 소개 (Project Overview)
> 개인적인 고민과 개발을 주제로 서로 소통하는 커뮤니티 서비스입니다.

---

## 💻 Front-end 소개
- 사용 기술: React, (예: Vite, TypeScript, React Router 등)
- 역할: 초기 화면 설계, UI 컴포넌트 구현, API 연동, 상태 관리 등
- 특징: (예: 반응형 디자인, 재사용 가능한 컴포넌트 구조 등)

---

## 🖥️ Back-end 소개
- 사용 기술: Express.js, (예: Node.js, JWT, MySQL, Redis 등)
- 역할: REST API 설계 및 구현, 인증/인가, DB 모델링 등
- 특징: (예: 계층형 아키텍처, 에러 핸들링, 로그 구조 등)
